# 编辑器接口错误合同草案

任务：M0-03。状态：草案，业务错误码需在实现前与现有项目错误码登记表合并。

## 通用传输语义

| HTTP/业务码 | 含义 | 自动续期 | 说明 |
| --- | --- | --- | --- |
| 200 | 业务成功 | 否 | `data` 按接口返回；空操作返回 `null` |
| 400 | 请求格式或授权类型错误 | 否 | 不创建会话、不写业务数据 |
| 401 | 缺失、失效或撤销的身份 | 仅独立访问令牌可按配置尝试一次 | 业务事务开始前拒绝 |
| 403 | 已认证但角色、租户、对象或动作无权限 | 否 | 不能用 401 混淆权限不足 |
| 404 | 对象不存在或不可枚举 | 否 | 跨租户场景可统一为 404/403，具体接口冻结时统一 |
| 409 | 锁、书签、状态或幂等冲突 | 否 | 返回当前可安全展示的冲突信息，不返回秘密 |
| 422 | JSON、四包、字段或引用校验失败 | 否 | 不部分写入 |
| 429 | 登录/接口/上传限流 | 否 | 可返回重试等待时间，不泄露账户存在性 |
| 500/503 | 服务或依赖不可用 | 否 | 不伪造空权限、空场景或成功保存 |

## 安全和错误消息

- 登录失败对外统一为“手机号或密码错误”，不区分租户不存在、用户不存在、密码错误或账号禁用；审计内部保存分类原因。
- 错误消息不包含密码、访问令牌、刷新令牌、锁令牌、票据、签名地址、SQL、堆栈或内部节点地址。
- `tenant-id` 不一致、请求体伪造用户/租户/操作者、编辑者编辑他人场景、只读用户写入、预览票据调用管理写入统一返回禁止或不可枚举错误。
- `saveAll` 的四包任一解析/引用/权限/锁校验失败，不更新草稿、书签、索引或发布指针。
- 相同 `requestId` 和相同规范正文返回原成功回执；相同编号不同正文返回幂等冲突，不执行第二次写入。
- 错误码的最终数值应复用现有项目异常枚举或在 `contracts/editor/errors.json` 登记，不在控制器中散落数字常量。

## 实现登记项

1. `/scene/{id}` 不可枚举时统一返回 403；只对公开票据使用 404 防止发布编号枚举。
2. 场景锁竞争使用 423，旧书签、状态和幂等冲突使用 409；具体业务详情写入 `data.reason`，不泄露对象或令牌。
3. 登录应用禁用、租户到期和用户禁用均拒绝新请求；会话缓存清理策略在 M1 实现测试中验证。
4. `code=200` 与 HTTP 2xx 成功一致；认证和权限失败使用对应 HTTP 状态及相同业务码，兼容参考服务的异常由请求层处理。
