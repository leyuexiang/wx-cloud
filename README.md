## 公开仓库发布说明

本版本为公开仓库快照：

- 环境配置中的密码、密钥、令牌和第三方 API 密钥已替换为 `${REDACTED_SECRET}` 占位符，部署时请通过环境变量或配置中心注入。
- 本地构建目录、压缩包和大型数据库导出文件未纳入版本库。
- 本次命名迁移已将微服务目录、Maven 坐标和 Java 包名从旧命名调整为 `wx`。
- 运行前请根据实际环境补充数据库、注册中心、消息服务和第三方平台配置。
