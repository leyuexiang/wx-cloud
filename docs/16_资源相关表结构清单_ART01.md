# 资源相关表结构清单（ART-01）

更新日期：2026-10-29。本清单来自测试库 `wx_editor_test148` 的实际结构，MySQL 8.0.46；全库 82 张表，此处覆盖 20 张既有资源/文件/场景关联表和 1 张新增操作表。系统短信、邮件和通知模板属于权限平台功能，未混入美术资源模板域。

字段、索引和外键以[结构快照](evidence/backend-art01-20261029/schema-after.json)为证据；[迁移前快照](evidence/backend-art01-20261029/schema-before.json)保留原核心表结构。此处不列任何业务记录、账号或存储配置内容。数据和 API 合同见[设计合同](15_资源模板数据结构与接口合同.md)。

## 关系与解释边界

- 新的三类目录 `resource_id` 显式关联 `wx_dim3d_resource.id`，由受控服务校验；本轮只回填可证实的同租户模型对应，目录关联没有新增物理外键。
- 旧模型 `model_file_id` 按已核实前端链路引用转换资源；旧图标/封面采用外部 OSS 合同，模板保留业务快照语义，不能把全部文件编号统一连接到 `wx_infra_file`。
- 操作表 `resource_id` 有外键；主表 `(id,current_operation_id)` 有指向同资源操作的复合外键。其它旧表未因名称相近自动建立外键。
- 旧资源项目、版本、分类、文件父级和场景关系保留在原域；迁移时须按真实消费者和旧命名空间映射。包依赖、贴图、Shader 和灯光由不可变清单描述，不为每个依赖重复创建资源主记录。

## 表导航

| 表 | 定位 |
| --- | --- |
| `wx_dim3d_resource` | 稳定资源主表：旧转换数据及新的当前内容指针。 |
| `wx_dim3d_resource_operation` | 本轮新增：幂等操作、验证进度、前后快照与提交回执。 |
| `wx_dim3d_model` | 模型目录：旧 model_file_id 保留，resource_id 为明确的新主资源关联。 |
| `wx_dim3d_icon` | 图标目录：旧 icon_file_id 是前端 OSS 合同编号，新关联单独保存。 |
| `wx_dim3d_template` | 旧模板目录：保留业务快照语义，不能自动等同可复用资源闭包。 |
| `wx_resource` | 旧项目资源兼容域，整数 ID 与 unique_id 不直接等于新资源 ID。 |
| `wx_resource_info` | 旧项目资源明细及原始 JSON，保留平台、项目及旧版本关联。 |
| `wx_resource_version` | 旧版本领域；不作为新单资源更新的前置。 |
| `wx_resource_type` | 旧资源分类字典；分类编号不是稳定资源 ID。 |
| `wx_resource_data_type` | 旧资源数据类型字典。 |
| `wx_material` | 旧材质库数据，保存预览、贴图和玻璃等参数；新 Unity 材质仍由包及清单交付，不复用此表假装已完成包依赖存储。 |
| `wx_icon_info` | 旧项目图标库，保留项目、unique_id 和文件路径。 |
| `wx_icon_type` | 旧图标分类字典。 |
| `wx_file_info` | 旧业务文件目录元数据，含 parent_id/unique_id 等逻辑字段。 |
| `wx_file_only_info` | 旧单文件/项目文件元数据，保留其父级和项目字段。 |
| `wx_file_download_info` | 旧文件下载记录，file_id 仅在原文件域解释。 |
| `wx_files_minio` | 旧 MinIO 上传/分块元数据，md5 和 upload_id 不替代新闭包的 SHA-256 及操作 UUID。 |
| `wx_infra_file` | 当前基础设施文件记录；不与旧外部 ossId 或转换 ID 无证据合并。 |
| `wx_infra_file_config` | 基础设施文件存储配置；这里只列结构，不记录配置值或凭据。 |
| `wx_infra_file_content` | 基础设施数据库存储文件内容；本轮不将 AssetBundle 二进制写入此表。 |
| `wx_scene_def` | 旧场景/实例数据域，nodes、components、版本和发布状态属于场景业务，不进入资源上传事务。 |
