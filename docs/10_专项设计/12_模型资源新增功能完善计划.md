# 模型资源新增功能完善计划

日期为 2026-11-12。本文以当前 `wx-vue-unity` 模型管理页面为消费者，承接已有 MARKET-03/04 和 ART 受控资源实现，按图片新增专项的完整业务验收方式收口模型新增功能。任务状态统一维护在 [03 近期执行任务](../03_近期执行任务.md#model-00-模型资源新增功能完善计划2026-11-12)。

## 1. 交付目标与本轮范围

用户在现有“新增模型”弹窗填写业务信息，选择模型压缩包，完成上传、转换和保存后，应能在列表中找到模型、查看封面和预览、重新打开编辑，并在当前支持的场景运行端加载和保存重开。

本轮交付本文及项目导航。后续实施依照下述工作项推进，分别登记合同、代码、迁移、部署、真实联调和用户验收。

| 功能范围 | 完成交付要求 |
| --- | --- |
| 新增弹窗 | 复用已有布局、分类、归属、封面、付费状态和模型文件控件，表单选项与后端实际能力一致 |
| 模型文件 | 当前入口接受单个压缩包（ZIP），包含一个 OBJ、FBX 或 3DS 主模型及依赖文件，原包上限为 500 MiB，前后端提示统一 |
| 模型转换 | 默认产出二进制模型格式（GLB），既有开放模型传输格式（glTF）输出能力按合同及真实样本分别验证 |
| 业务保存 | 名称、描述、分类、归属、封面和已有计费字段准确落库，模型目录与可消费内容关联可靠 |

## 2. 当前事实与差距

### 2.1 用户请求与只读现场核对

- 用户截图显示 `POST /admin-api/dim3d/model-imports` 返回业务码 `404`，提示 `请求地址不存在:admin-api/dim3d/model-imports`。截图未展示传输状态，实施时同时记录超文本传输协议（HTTP）状态和业务码。

## 3. 完整用户流程

1. 打开弹窗，读取启用模型分类及当前身份允许的归属，加载已有计费规则和封面上传能力。
2. 填写名称、描述、分类、归属、可选封面及计费信息。上传前校验字段，明确创建时固定的数据和发布时提交的数据。
3. 选择 ZIP，前端检查类型、空文件和 500 MiB 上限，通过工作线程分块计算摘要，显示可取消的校验进度。
4. 生成一次操作编号，创建或重放原导入任务。后端根据真实登录身份分配稳定资源编号，绑定源大小、摘要和输出格式。
5. 请求原包上传目标，浏览器将 ZIP 直接上传到签名地址，成功后提交原操作进入队列。
6. 后台冻结并核验原包，调用真实转换服务，校验模型与贴图闭包，进入等待发布确认阶段。
7. 用户点击保存，固定经过校验的完整目录信息。已有确认请求重放返回同一结果，最终事务同时提交资源修订、目录、封面绑定及操作回执。
8. 取得同一操作的最终提交成功状态后，前端显示“模型新增成功”，结束当前等待并刷新列表、分类数量和封面。
9. 从列表打开详情及预览，通过稳定资源编号读取已提交修订、模型清单和允许成员的临时地址。
10. 重新登录、刷新或重开编辑时从服务端恢复真实目录及任务状态。模型拖入场景、保存并重开后能恢复相同资源引用和实例数据。

上传完成、转换完成、等待保存、发布受理和最终提交在界面分别呈现。原文件上传后的等待阶段保留操作编号和表单；用户可关闭弹窗后重新查询。

## 4. 接口与业务合同

### 4.1 现有接口与补齐要求

下表导入路径基址为 `/admin-api/dim3d`。开发时同时核对网关、运行控制器及前端接口适配（API）调用。

| 接口 | 现有语义 | 完善要求 |
| --- | --- | --- |
| `POST /model-imports` | 创建或重放原操作，固定原包身份 | 校验真实角色、系统/租户范围、字符串编号、请求摘要及来源，拒绝冲突输入 |
| `POST /model-imports/{operationId}/source-target` | 空对象请求，返回原 ZIP 的短时 PUT 上传目标 | 仅在允许阶段签发，固定对象键、大小和摘要，地址可由工作站浏览器访问 |
| `POST /model-imports/{operationId}/submit` | 原操作持久化入队，首次受理 HTTP 202，已提交重放 HTTP 200 | 重复/并发受理保持单任务，独立核验实际原包 |
| `GET /model-imports/{operationId}` | 查询原操作和导入阶段 | 成功从原提交回执派生，稳定返回错误码、可重试标志及已提交修订 |
| `POST /model-imports/{operationId}/publish` | 固定目录信息并受理发布 | 扩展并冻结封面、计费信息等现有表单字段，分类与权限由服务端复核，重复确认幂等 |
| 计划中的导入 `retry/cancel` | 当前导入控制器尚无专用端点，既有资源服务已有取消入口 | 先核对可复用能力及模型阶段投影，再按合同接入；形成真实重试和取消结果 |
| `GET /model/page`、`GET /model/info/{id}` | 模型目录分页及详情 | 目录编号与受管资源编号分别返回；统一分页投影、筛选、状态和分类计数 |
| `PUT /model/edit/{id}` 及既有状态、删除接口 | 目录维护 | 校验归属与可编辑字段，受管资源关系由受控流程维护，删除覆盖场景引用保护 |
| `GET /resources/{resourceId}/current`、`GET /resources/{resourceId}/file` | 已提交资源描述及固定成员签发 | 支持普通模型清单分支，签发限定修订、摘要和文件集合，覆盖签名过期续取 |
| 图片上传及按编号读取 | 模型封面的普通文件来源 | 复用 IMG 文件身份和归属检查，封面读取符合模型可见范围 |

创建的 `resourceScope` 与页面归属映射为 `SYSTEM → GLOBAL_SYSTEM`、`MINE → TENANT_SHARED`。服务端仍从真实操作者及租户校验权限。系统资源当前授权要求平台登录租户配置和 `super_admin` 角色，租户资源要求本租户及 `tenant_admin` 角色；修改该规则须同步权限合同。

### 4.2 表单与保存规则

| 字段 | 统一要求 |
| --- | --- |
| 模型名称 | 目录字段 2～50 个字符，清理首尾空白；创建元数据与最终目录名称的关系在合同中固定 |
| 描述 | 对齐当前页面 200 和后端 500 的差异，沿用已冻结的业务上限并同步两端提示，保全已有可读取内容 |
| 分类 | 使用真实启用字典编码，服务端检查分类用途；明确任务期间分类停用后的可修正失败方式 |
| 归属 | 创建时固定，发布及替换复核，表单修改后明确重新创建操作的条件 |
| 封面 | 可选稳定图片文件编号，检查存在、归属和用途；首次创建保存封面，替换未选新封面时保留原值 |
| 计费字段 | 租户端按现有免费规则，运营端按既有权限保存免费/付费状态及价格；价格沿用整数分存储并检查转换边界 |
| 模型文件 | 受管模型使用稳定 `resourceId` 和内容修订，旧文件编号沿用历史语义 |

目录确认请求、接口样例和机器可读结构一并更新。封面绑定、分类校验及新增字段的失败回滚应在实现前形成可评审的软件设计说明（SDD）。

固定发布输入前完成目录、分类、封面及金额校验，未固定的输入可修正后重提。已固定输入按原数据重放，后续业务修改通过目录编辑或符合合同的新操作处理。

## 5. 数据、身份与事务

- `wx_3d_model.id` 为模型目录编号，`wx_3d_resource.id` 为稳定资源编号，`operationId` 为一次业务操作编号，`currentRevision/committedRevision` 为内容修订。封面编号关联 `wx_infra_file.id`。接口与前端适配明确各动作使用哪一类编号，全部对外按字符串传输。
- 复用 `wx_3d_resource_import`、原资源操作及修订记录。导入成功以同一 ART 操作的 `COMMITTED` 和 `committedRevision` 为依据，状态投影通过该事实校正。
- 受管目录通过 `resource_id` 关联普通模型，旧记录通过原文件字段读取。管理页须保留两种身份，受管预览直接走清单和资源成员签发分支。
- 数据迁移核对既有 ART 目录关联迁移与 MARKET `001/002/003` 的实际结构，包括来源、任务表、UTC 时间、发布描述、目录空旧文件编号及约束。按 `wx_editor`、`wx_editor_data08` 对应运行实例登记差异和授权批次。
- 新增字段、索引及合同采用新的可审计增量。保留原有模型、目录、任务和发布引用，历史来源仅在证据充分时分类。
- 文件读写和转换在数据库持锁事务外执行；最终短事务按既有资源行、操作行、任务行顺序复核权限、租约、输入、取消和预期修订，再提交目录、修订、指针和回执。
- 封面文件绑定纳入同库事务设计，统一行锁顺序。发布失败回滚目录、资源指针与封面归属，保留可恢复的私有源和产物。
- `REPLACE` 保持稳定资源编号并带 `expectedRevision`。并发冲突返回明确结果，已加载实例按原固定修订继续使用，新上下文依合同取新修订。

## 6. 存储、转换及运行配置

### 6.1 存储与浏览器传输

现有模型存储候选沿用 MinIO 私有桶 `wx-art-test148`，实施前复核三维服务实际桶、凭据来源及对象权限。图片封面使用基础设施文件服务，模型 ZIP 和产物使用现有 ART 对象存储。

- 原包暂存使用服务端生成的 `resources/staging/model-imports/{operationId}/source.zip`，源冻结和产物使用各自尝试前缀，最终内容以清单及不可变前缀定位。
- 图片专项 `9000` 接口配置可用于连通参考。模型签名器当前要求安全传输协议（HTTPS）端点，上传、下载配置及前端校验须共同核对。
- 分别验证 `dim3d.resource.upload-endpoint`、`download-endpoint` 与浏览器可达地址、可信证书、签名主机、反向代理路径编码及跨源资源共享（CORS）。保留签名查询参数和上传方法，浏览器不把业务认证或租户请求头带到对象上传地址。
- 上传与下载都按精确来源配置；下载默认继承上传来源，也可单独覆盖。代理使用互不冲突的映射变量，旧来源按实际消费者保留，禁止因修复跨域开放通配来源或桶匿名读取。
- 全链路检查 500 MiB 源文件的代理限制、连接超时和工作站网络。签名到期允许原任务在合法阶段重新取地址，源冻结后读取已固定内容。
- 源 ZIP、转换 ZIP 和最终模型分别保存身份与摘要。持久化记录只保存稳定身份和对象键，签名地址按需生成。

### 6.3 转换与产物验证

对 OBJ、FBX、3DS 分别提交当前页面要求的 ZIP，通过真实转换接口产出 GLB；既有 glTF 输出按格式单独测试。记录工具和镜像版本、依赖可执行性、带贴图和必要动画的代表样本。

转换服务存活、工具就绪和转换成功分别判断。响应为 HTTP 200 时仍检查业务结果、ZIP 内容类型与实际字节，现有 `CONVERT_FAIL`、超时、繁忙和断连映射到稳定错误。

产物校验覆盖安全路径、重复项、文件数、展开大小、单模型入口、GLB 头与块长、glTF 缓冲及贴图引用、实际文件摘要和清单闭包。对外部链接、目录越界、损坏压缩包、压缩炸弹和缺失依赖给出明确失败。

普通模型保持 `wx.model-resource.v1`、`model.glb.v1/model.gltf.v1` 分支，源 ZIP 和转换 ZIP 保留为后台材料。清单中的平台和兼容标识按实际运行端验证，Unity 热更资源继续沿用其既有格式分派。

当前普通模型合同的平台值为 `WebGL`。实际运行工程构建与清单平台字段的兼容映射在 MODEL-01 冻结，并在 MODEL-07 使用真实加载器验证。

## 7. 异步任务、恢复与生命周期

正常阶段为 `RECEIVING → QUEUED → VERIFYING_SOURCE → CONVERTING → VALIDATING → PUBLISHING → COMMITTED`。`PUBLISHING` 既包含产物已校验待确认，也包含确认后发布中的任务，前后端需有稳定可辨识的投影或动作能力字段。

| 情况 | 要求的结果和恢复方式 |
| --- | --- |
| 创建、上传或入队响应丢失 | 保留原操作编号及不可变输入，先查询再重放；同一次导入维持一个资源身份 |
| 上传失败或地址过期 | 合法阶段重新签发原目标，独立校验实际源大小和摘要 |
| 队列等待、转换和等待保存 | 显示真实阶段、可执行动作和错误，界面禁止无效重复上传及保存 |
| 可重试失败 | 服务端重试复用已冻结源或已固定产物，维护尝试编号及原操作截止时间 |
| 输入损坏、终态或产物已丢失 | 返回明确不可恢复结果，引导用户修正文件或按允许规则创建新操作 |
| 关闭弹窗或切换身份 | 结束本地摘要线程、请求及轮询；后台任务按持久化状态继续，重开先服务端查询 |
| 用户取消 | 复用既有取消服务并补齐导入投影、租约和子任务协同，在同一锁顺序下裁决取消与提交竞争 |
| 后台重启或租约到期 | 以数据库时间和尝试编号恢复；迟到响应无法覆盖新尝试或已经提交的修订 |
| 目录保存失败 | 目录、指针和封面关系按事务回滚，保留可查询原任务和表单，允许合同规定的重试或修正 |
| 删除和清理 | 先校验目录、场景、模板、发布与在途任务引用，保留审计及固定产物身份 |

前端在弹窗可见时使用单个受控查询循环，设置间隔、退避和截止，终态、关闭、卸载或身份变化时释放。当前会话恢复复用已有实现，登录刷新及恢复范围在合同中明确，签名和文件字节不进入会话持久化。

源文件及固定产物先沿用既有保留规则，完善可配置保留期、引用检查和运维清理记录。清理先预演并定位确切对象集合，原包、在途尝试、可重试产物和已发布引用按各自规则处理。

## 8. 性能与资源约束

- 复用前端分块摘要工作线程，避免把 500 MiB 原包一次复制到主线程；页面卸载关闭线程和临时对象地址。
- 后端沿用流式传输和临时文件上限，及时关闭压缩包、文件流、存储响应及转换请求，失败和取消路径同样释放资源。
- 后台队列有界领取，转换槽位、轮询线程和租约续期分别受控。基于现有实现核对多实例竞争和索引，按测量结果调整并发。
- 模型清单和 ZIP 成员用映射与集合做一次索引，限制数量、展开总量及可消费闭包规模，避免重复解压和无界嵌套遍历。
- 列表按页读取目录和资源摘要，批量或有界解析封面与成员地址；分类计数优先同口径聚合，保留单文件接口时限制并发并去重。
- 临时签名缓存按身份、资源、修订、成员及有效期隔离。预览关闭和模型切换后释放几何、材质、贴图、请求及渲染句柄。
- 使用小模型、带贴图代表模型及上限附近源包分别测量摘要、上传、排队、转换、首屏、内存、临时磁盘与释放结果。指标依据样本、硬件和网络基线确定。
