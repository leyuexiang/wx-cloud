## 二、SSH 登录

Windows PowerShell：

```powershell
ssh -o IdentitiesOnly=yes -i "$env:USERPROFILE\.ssh\wx-cloud_codex" root@192.168.10.148
```

当前私钥路径：

```text
C:\Users\Administrator\.ssh\wx-cloud_codex
```

备用私钥路径：

```text
C:\Users\Administrator\.ssh\wx-cloud_ed25519
```

服务器端权限修复：

```bash
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys
restorecon -Rv /root/.ssh 2>/dev/null || true
```

## 六、常用检查命令

### 系统资源

```bash
hostname
cat /etc/os-release
nproc
free -h
df -h
uptime
```

### Java 与进程

```bash
java -version
mvn -version
jps -lv
```

### Redis

```bash
systemctl status redis --no-pager
systemctl is-enabled redis
redis-cli ping
```

启动并设置开机自启：

```bash
systemctl start redis
systemctl enable redis
```

### Nacos

```bash
docker ps --filter name=nacos
docker logs --tail 100 nacos
curl -sS -m 5 http://127.0.0.1:8848/nacos/v1/console/health/liveness
```

### 数据库

```bash
mysql --version
systemctl status mariadb --no-pager
```

### Kafka

```bash
docker ps --format '{{.Names}} {{.Image}}' | grep -i kafka
(ss -lntp 2>/dev/null || netstat -lntp 2>/dev/null) | grep -E ':9092|:29092|:9093'
```

## 八、安全注意事项

1. 不要将 root 密码、私钥文件或私钥口令提交到 Git。
2. `wx-cloud_codex` 为临时运维私钥，任务完成后应删除服务器公钥和本地私钥。
3. Redis 若监听 `0.0.0.0:6379`，应配置访问控制和防火墙白名单。
4. CentOS 8 已停止维护，后续建议迁移到 Rocky Linux、AlmaLinux 或其他受支持版本。
5. MariaDB 10.3 与项目 MySQL 基线存在差异，部署前应完成兼容性验证。
