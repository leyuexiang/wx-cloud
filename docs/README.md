# 项目设计文档索引

## 当前设计基线与阅读顺序

当前优先形成平台总体设计，版本为V1.0评审稿；文档完成不表示用户已确认或功能已实现。

1. 先看[00 总体架构与改造路线图](./00_数字孪生平台总体架构与改造路线图.md)：评审六个领域、云边职责、身份、数据归属、版本发布和阶段出口。
2. 再看01、02、03专项设计：细化BIM、IoT、规则及流程的接口和数据契约。
3. 04用于逐项投标响应，性能、精度及格式能力以实施验证材料为依据。
4. 05、06保留RVT后续验证方法和已有预检事实；解析引擎、插件及授权选型不作为总体设计评审的前置。

## 命名规则

- 平台总体与跨领域设计按实施依赖排序，使用两位数字前缀：`NN_领域_文档主题.md`。
- 专项设计和投标响应分别命名，避免把实施设计与招标响应混为同一份文档。
- 本项目的架构、专项设计和相关操作手册统一存放在`docs/`；不再在仓库根目录或`db/`下并列保存此类文档。
- 文档调整名称时同步更新相对链接；归档前先确认没有尚未吸收的独有技术内容。
