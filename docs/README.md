## 5. 命名与维护

- 文档采用 `两位序号_主题.md`，目录内独立编号；分类目录同样带序号。根目录 00～03 固定为日常入口，不按对话次数不断新增规划。
- `README.md` 是工具通用入口，`evidence/`、`templates/`、合同文件和执行脚本保留原名称，避免破坏工具及证据引用。
- 新方案放对应分类；修改既有方案时更新原文件，不同时维护“最新版/最终版/新规划”等副本。
- 任务状态只在 03 维护，00 保存当前指针；完成证据进入独立日期/批次目录。
- 路径移动同步修复仓库内链接；仅对外部仓库提示新路径，不越界批量改写其源码。
