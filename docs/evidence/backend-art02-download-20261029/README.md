## 授权和清理边界

授权下载地址本身是一张短时通行凭证，持有者在有效期内可以使用它。换租户或撤权会阻止重新签发，不承诺撤回已经发出的地址；撤销窗口上限为 300 秒。测试中的“跨租户拒绝”指其它租户不能通过资源 API 获得共享资源描述及签名，无签名存储读取被拒绝。

使用独立前缀和标记的合成 JSON 文件、手动元数据夹具验证读取，结束后已清理文件、主记录和操作。手动 READY 夹具不能作为 ART-03 校验/提交证明；没有上传真实汽车、灯光或植被，也没有画面测试截图。

测试证书为原内网验收证书，主机名为服务器IP，有效期截至 **2026-11-11 12:54:09（北京时间）**。当前显式跨域白名单为本机测试页 `http://127.0.0.1:8765`；其它业务宿主域接入时需更新明确白名单和证书信任。此入口是测试配置，不等于长期正式域名与证书部署。
