## 实现范围与限制

- 本轮只部署数据库增量结构。新 Java 持久化映射和旧目录请求保护已在本地编译/测试，未替换运行中的 Java 包，也未重启服务。
- 新 API 路径和错误码已形成合同，尚未实现实际全局/租户资源查询、受限上传授权或单资源对象校验/提交。20 项回归验证当前运行服务与新结构兼容，不能外推新接口已通过。
- 包依赖、灯光闭包及 MinIO 对象未执行真实上传替换，Unity 新接口适配和普通汽车/烘焙汽车/植被视觉仍未验收。本轮无画面测试，也没有新增视觉截图。
- 当前保留策略为旧对象及快照不自动物理清理；清理任务默认不启用。启用新写入后不能直接删除结构回退，执行器会拒绝存在新数据/操作/关联改动的降级；后续改表应使用新迁移。
- 初始部署曾出现的冷启动权限查询异常根因仍待观察；30 天测试授权状态未在本轮改变，后续持续验证前仍须检查有效期。
