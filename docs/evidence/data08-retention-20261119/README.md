## 实现及失败语义

- 新修订与请求记录同事务插入，记录失败时整笔回滚；请求摘要、修订号和到期时间不会被后续写入覆盖。
- 保留期限默认 30 天；重放不续期，到期返回 409，需使用新请求号。保留修订原有唯一键。未回填历史请求沿用旧重放行为，并阻止回收。
- `POST /dim3d/scene/bookmark/{sceneId}` 创建固定修订引用；同键重试返回原书签，不换版、不续期。期限限定 60～86400 秒。
- `DELETE /dim3d/scene/bookmark/{sceneId}/{bookmarkId}` 仅允许创建者幂等撤销；撤销行保留，场景软删除后也可以释放引用。两个入口均要求平台或租户管理员角色。
- 所有编号由服务端生成并对外使用字符串，客户端不能指定可信租户和操作者。审计比对请求摘要和修订号；时间使用数据库纪元秒，未知状态和缺失记录继续保全。
