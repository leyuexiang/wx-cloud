# 专用物联网握手、协议容量与单浏览器验收

2026-11-17，IOT-M3-05E。用户确认本轮为协议容量与单浏览器；50 个真实播放器暂不推进。

## 交付与认证边界

物联网前端默认连接 `/dimensions/ws/iot-state`，服务端通过 `wx.iot-state.websocket-path`、前端通过 `VITE_IOT_STATE_WEBSOCKET_PATH` 配置路径，保持已有同源和固定发布网关选址。服务端在升级前校验真实管理员租户身份、到期时间、订阅权限及显式租户一致性。专用处理器不触发旧任务队列中断和历史重放；入站只注册订阅、退订，出站仅允许四种物联网消息。其他共享消费者保持兼容。

[正式握手](formal-handshake.json)与[候选握手](candidate-handshake.json)：匿名和无效令牌 HTTP 401，无订阅权限及伪造租户 HTTP 403；合法连接、心跳、未知类型后的合法消息以及草稿代理通过。旧 `/dimensions/ws` 仍允许匿名握手，匿名物联网订阅仍被拒绝；本轮没有把旧共享入口改成认证专用入口。

多节点正常会话未命中的日志改为调试级别（DEBUG）元数据，不再记录正文。实际旧节点在 120 秒窗口产生 173220270 字节日志、214200 条未命中记录，见[真实诊断窗口](log-pressure-initial.json)；[较晚空闲窗口](log-pressure-before.json)不能替代该诊断。日志与历史重放分别存在开销，尚不能认定其中一项是首次高延迟的唯一原因。

## 实际容量与首次延迟

一个模拟网关 MQTT 连接汇聚 1000 个逻辑设备，每五秒一条，50 条同账号认证连接各订阅全部测点。并非 1000 个 MQTT 连接、50 独立身份或 50 个播放器。此前[独立身份证据](../iot-identities-20261117/README.md)对应旧包，不能冒充新包复测。

| 轮次 | 实际结果 |
| --- | --- |
| 候选旧共享入口首次 | 4184 条已确认上报、209200 次推送最终完整；积压保护停止，第 95 百分位 11622 毫秒，未通过 |
| 候选专用入口首次短测 | 2000 条、100000 次完整，第 95 百分位 106 毫秒 |
| 正式代理修正后首次短测 | 2000 条、100000 次完整，第 95 百分位 147 毫秒 |
| 正式十分钟 | 120000 条、6000000 次完整，零重复及客户端错误，第 50/95/99 百分位 81/994/3995 毫秒 |

各轮原始报告：[旧共享入口](legacy-first.json)、[候选新入口](dedicated-candidate-first.json)、[正式短测](dedicated-formal-first-routed.json)、[正式十分钟](dedicated-formal-10min-routed.json)。十分钟持续发送 600.038 秒，结束后 0.2 秒排空，50 张票据全部撤销。保留逐分钟交付、续租确认及[主机采样](formal-system-samples.json)。延迟由同一发生器单调时钟统计，一毫秒向上取整；五秒工程观察门槛未放宽，尚未替代业务签收指标。

旧、新测试的顺序、时长和日志配置不同，不能当作受控冷启动因果实验。专用入口短测及稳态已过，仍需在受控环境重复冷启动测量，不能宣称首次延迟彻底解决。

## 原发布与单浏览器

[原固定发布接口回归](published-regression.json)覆盖错误域、实例、点位、旧修订借用草稿、伪造租户、重复、乱序、重连快照和票据撤销。第一次回归在容量运行期间读取管理接收记录超时，尚未发送重复消息；清理连接及票据后，容量结束再执行本报告并通过，不将首次超时写成通过。

ego-browser 继续使用任务空间 1。旧预览页经堆对象诊断超时后交还用户；用户关闭旧页并明确允许重新接管。接管时该空间只剩其他用户页面，于同一空间新建一个原发布预览，其他页面保持。通过正常租户登录，原发布 `PUB-2122542758537261058`、修订 5 自动签发短期票据并加载。

- [首屏](browser-new-baseline.json)：实际路径 `/dimensions/ws/iot-state`，两个订阅确认、两次快照，一次播放器加载，温度 29.500。
- [实时更新](browser-new-realtime.json)：真实 MQTT 上报后显示 28.625，同一文档，快照仍两次，没有保存提交。
- [断线恢复](browser-new-reconnect.json)：浏览器离线开关未能阻止套接字重建，不能据其宣称断网通过。实际关闭本页已记录的专用连接，并暂时阻止该页重建连接；全部连接关闭期间真实上报 27.750，恢复后两次快照补齐。此为可撤销的页面传输故障注入，未模拟主机或现场网络故障。
- [恢复实时](browser-new-restored.json)：随后 29.500 通过真实推送恢复。累计六次快照包含两次真实连接关闭后的各两次补偿，不应写成重连只增加两次的累计结论；最终受控故障单次增量为两次。

验收后重载清除观察器和故障注入，显示恢复为 29.500，见[最终页面](browser-final.json)。截图命令本轮超时，没有重试截图或将历史图片当作本轮画面证据；页面文本与实际连接消息留证，任务已结束并保留结果页。旧文档和未使用的五张验收票据[已撤销](browser-ticket-cleanup.json)，最终结果页自己的后续票据保留。ego lite 提示更新，未升级。官方 Unity 插件本轮没有可连接编辑器，不将网页验收写成编辑器联调通过。
