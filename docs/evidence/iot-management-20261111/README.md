## 使用和回退

在SSH隧道或服务器回环地址调用系统API。受控凭据文件可为`tenantId/username/password`对象，也可复用服务器身份数组，默认选择`super_admin`。凭据不得作为命令行值传入，不能存入仓库；远端HTTP登录被拒绝，远程调用须使用HTTPS或回环SSH隧道。

```powershell
python deploy/test148/management_menus.py inventory --output <离线清单路径>
python deploy/test148/management_menus.py plan --base http://127.0.0.1:<隧道端口>/admin-api --credentials <受控文件路径> --output <现场计划路径>
python deploy/test148/management_menus.py apply --base http://127.0.0.1:<隧道端口>/admin-api --credentials <受控文件路径> --plan <现场计划路径> --output <本次执行记录路径>
python deploy/test148/management_menus.py rollback --base http://127.0.0.1:<隧道端口>/admin-api --credentials <受控文件路径> --receipt <本次执行记录路径> --output <独立回退记录路径>
python deploy/test148/management_menus.py role-plan --receipt <成功执行记录路径> --role-menus <目标角色现有菜单编号数组文件> --mode read --output <角色增量预览路径>
```

示例尖括号均为待替换参数，实际文件保存在受控发布目录。输出文件存在时拒绝覆盖。角色预览还须附目标租户/角色及套餐校验，再经系统分配接口执行；工具本批不自动授予角色、变更套餐或删除菜单。
