## 现场问题与修复

1. 宿主为 MariaDB 10.3，与源码迁移要求不兼容，因此建立独立 MySQL 8。
2. 既有服务占用旧内部端口，因此采用新的回环端口，并同步网关、服务调用和健康检查。
3. Docker 旧代理不可达。通过可用通道下载并逐层校验摘要后导入镜像，没有重启 Docker。
4. 首次业务检查发现授权文件不可读。根因是旧容器以管理员用户运行，而镜像默认为 `100:101`；修正目录归属并补充回归后，正式切换前的 20 项接口验证全部通过。
5. HTTPS 验收进程继承同一失效代理。验收改为内网直连，保留证书链与主机名验证，真实下载及上传全部通过。
