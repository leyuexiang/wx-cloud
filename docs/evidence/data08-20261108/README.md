## 摘要算法样本（本地）

服务端新增 `SceneRevisionContentHasher`，使用固定编码版本、结构版本、四包数量、逐包 UTF-8 字节长度和原始字节计算 SHA-256。`SceneRevisionContentHasherTest` 共4项通过，覆盖摘要稳定性、分包边界、结构版本、空值校验和重复正文测量。

20条本地样本按5条共享同一正文：原始正文 2,340 字节、唯一正文 468 字节、4个唯一摘要，按正文共享计算可减少 1,872 字节（80%）。该结果只验证算法与测量口径，不外推148真实收益，也未创建测试库或写入148。
