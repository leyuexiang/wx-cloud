# 独立身份协议容量与单浏览器验收

2026-11-17，IOT-M3-05D。按用户确认，本轮收口为协议容量和当前电脑上的单浏览器；50 个真实播放器不列入本轮通过范围。

## 范围与正式身份

- 1000 个逻辑设备每五秒上报一次，一个模拟网关 MQTT 连接汇聚；50 个独立查看账号各自登录、各自一条 WebSocket 连接和一张固定发布票据，每人订阅全部 1000 点位。
- 管理站点的精确代理没有开放账号管理路由，原先的 404 不能代表系统没有接口。本轮使用平台管理员自己的真实租户身份调用正式回环网关，创建临时套餐和独立验收租户，再用该租户管理员创建账号及角色。没有伪造租户头、修改原租户 2 权限或直接插库。
- 现有套餐缺账号管理动作菜单，正式接口新增七个隐藏临时权限定义，仅加入本轮独立套餐。查看角色复用两个状态权限，并补齐没有动作权限的祖先菜单 111、122；所有 50 个账号的非空权限恰为 `dimensions:iot-state:query`、`dimensions:iot-state:subscribe`。用户列表和场景保存实际返回 403。见[准备回执](provision.json)、[逐身份核对](identity-checks.json)。
- 工具从标准输入接收可选 `viewers` 列表，以登录响应的服务端用户编号去重；夹具管理及票据签发保持独立管理身份，查看用户没有管理权限。账号、密码及票据只进入受限文件和进程内存，不进入本证据；服务器明文身份文件权限为 0600，验收后删除。

## 单浏览器实际操作

ego-browser 复用任务空间 1 和原发布预览页，不增加第二个播放器。进入时原登录会话已经到期，页面显示登录表单；通过正常登录后场景恢复，授权快照显示此前真实 MQTT 上报的 `27.250°C`，随后负载期间再次上报 `29.500°C`，页面实时变化。

该页面消费原试运行场景的测点；1000 点夹具用于协议负载，不将这张页面当作千控件或千模型的渲染验收。

该文档自上一轮持续存在，累计播放器加载从 1 变为 2、快照从 2 变为 4，增量发生于本轮重新登录后的场景恢复。以恢复完成时为基线，后续温度更新没有额外播放器加载、状态查询或保存提交；不能将跨认证恢复的累计次数写成“总共加载一次”。见[页面观察](browser.json)及[负载时真实画面](single-browser-under-load.png)。自动票据续期的先前证据见[05C](../iot-soak-20261117/README.md)，本轮没有重新等待完整续期周期。

任务空间已结束并保留结果页。ego lite 提示可更新，本轮未升级。官方 Unity 插件仍未发现可连接编辑器，画面来自已部署网页播放器，不属于编辑器联调验收。

## 权限边界及设计差异

[实际边界报告](security-checks.json)：跨租户借用有效发布票据返回 `FORBIDDEN`，无订阅权限的同租户用户持有效票据仍返回 `FORBIDDEN`，伪造握手租户返回 HTTP 403。

**共享 `/dimensions/ws` 允许匿名握手，匿名 IoT 订阅返回 `FORBIDDEN`。** 首次边界脚本错误地假定匿名握手本身会失败，断言失败后仍执行连接关闭、票据撤销和会话注销；随后按实际共享端点复验并明确记录握手接受与订阅拒绝。原设计“未登录握手被拒绝”尚未达到，不能把消息授权拒绝当作握手准入通过；专用 IoT 握手准入继续待实施。该结论没有放宽点位授权或修改业务实现。

## 准备及回收中的限制

- 首次临时菜单名称重复，在正式接口拒绝后按清单续做，没有覆盖现有菜单。
- 创建账号接口允许 4～30 位，登录接口只允许 4～16 位。首个临时租户的长管理员账号不能登录，因此通过平台接口停用并删除该租户，后续账号全部使用两合同共同允许的短名称。本轮没有修正这个既有接口不一致。
- 成功租户的 50 个查看账号、查看角色及工作管理员已删除。工作管理员删除自身后，首次退出返回 400：源码顺序为先删除访问/刷新令牌，再记录登出日志；日志所需账号已不存在。清理分支再次退出后继续由平台身份回收租户。最终只读核对本轮租户的活动访问令牌为 0，此现象仍作为退出日志一致性缺口记录。
- 两个自动创建的系统管理员角色受服务保护而保留；失败首测的自动管理员行随已删除租户隔离保留。没有直接改库删除系统角色。成功租户自动角色有一条指向已删除临时菜单的关联行保留，有效菜单数为 0；不能把有效权限回收写成物理关联行清零。
- 两个临时租户、临时套餐及七个菜单已删除，原租户 2、原套餐、原菜单及原有角色授权逐项前后对照一致。最终没有处于活动临时租户中的活动用户。见[身份清理](identity-cleanup.json)、[最终只读审计](final-audit.json)。

本轮累计 124000 条接收审计全部 `PUBLISHED`，与代理确认一致；测试发布的 151 张票据均撤销。1000 个绑定、临时场景/连接器、隔离接入与代理、证书副本、辅助脚本、转发及明文凭据已回收。原场景仍为 3 个，原发布及修订 5 保持。接收/发布审计及受保护的系统记录按上述范围保留。见[数据清理](cleanup.json)、[主机清理](host-cleanup.json)。
