# 跨租户票据验收清单

该清单用于 148 隔离环境，只读核对和临时样本清理完成前不得标记真实联验通过。

- 来源租户创建并发布固定修订，记录 `publicationId`、`revisionNo`、`sourceHash` 和依赖摘要。
- 目标租户不能直接读取来源租户发布编号，未授权请求必须返回业务拒绝。
- 仅通过显式共享授权后，目标租户才能取得约定范围内的只读票据或实例化结果。
- 票据验证固定到发布记录，不能回查来源租户当前草稿或当前资源指针。
- 来源发布撤销后，目标租户旧票据验证失败，已产生的实例记录仍可读取。
- 共享授权撤销后不删除发布记录、票据历史或已创建实例，后续新请求必须拒绝。
- 清理来源场景、模板、发布记录、票据和授权样本，核对原有业务记录摘要不变。

本轮只冻结清单，未在 148 写入样本，也未执行真实跨租户票据联验。
