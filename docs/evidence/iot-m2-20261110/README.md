## 部署交接与剩余事项

- 只读核查148现有容器未见IoT服务；测试容器已清理，现有网关/系统/基础设施/三维服务没有重启。
- 需要在实际目标库核对IoT三表及历史运行字段，仅做适用增量迁移；本批没有重跑初始化或在业务库创建/删除IoT表。
- 经系统菜单接口按清单逐级创建/复用目录与页面；清单仅根目录提供parentId=0，子项必须根据parentKey补上父节点真实返回的parentId后才能提交。角色同时选择目录/页面与对应query按钮，写入动作单独授权，并核对租户套餐；不要直接SQL绕过菜单/角色缓存。
- 部署IoT服务及精确网关路由后，验证真实登录、菜单进入、增改查/分页、旧版本冲突、无权限及跨租户拒绝。保存候选摘要、现场备份、迁移清单与本批回退步骤后才能记录已部署。
- MQTT工作进程保持关闭亦可验管理闭环；连接测试与人工重放的成功路径分别需要受限Broker凭据/主题和Kafka。本批未用真实Broker/Kafka验成功，不标整链或M2总里程碑完成。
- 绑定内部设备/场景/对象仍为既有映射键；完整资源归属及三维消费联验待真实业务样本，不能凭输入字段宣称已校验全部对象授权。绑定暂无乐观锁，页面明确多人编辑限制。
