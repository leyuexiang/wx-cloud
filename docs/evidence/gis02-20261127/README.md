## 抽样方式

沿用 [GIS-01](../gis01-20261127/README.md) 正式目录的 5 个来源，逐一覆盖其已登记最高层级以内的每个层级，共 61 个“来源与层级”组合。

- 120 MinIO 已登记路径每层只读取最多 4 条对象索引，选择其中首尾两个实际对象；没有全量枚举或随机空间覆盖保证。
- 120 DEM 90m 按原 `layer.json` 每层可用范围首尾节点取样，同一节点去重。
- 实际读取 110 个不同瓦片；并发 2，单次连接/读取超时 3/8 秒，响应上限 8 MiB，地形解压上限 16 MiB。不使用业务凭据或环境代理，不跟随重定向。
- 每个样本比较 148 同源入口与原 110/120 服务字节；有对应 MinIO 路径的 87 个样本另与 120 原对象比较。源站只使用读取请求。
- 影像实际解码并核对 256×256 尺寸及格式；地形检查几何头、顶点差分解码、三角形与边界索引、扩展长度。格式依据 [Cesium 量化网格规范](https://github.com/CesiumGS/quantized-mesh)，这不表示高程或空间坐标精度已验收。
