# 网关令牌撤销一致性验收

2026-11-18，IOT-M3-05I。移除网关本地认证身份缓存，两个正式网关已部署；真实双节点预热后，用户退出和管理员从另一节点撤销均立即使后续权限查询返回业务码 401。认证依赖故障的拒绝转发由单元测试验证，未在共享身份服务制造故障。既有已转发请求及已建立连接不在追溯取消范围。

## 方案与源码

功能源码 `e40d0209309ae69aa7f85df56debe7162249f305`，只修改 `TokenAuthenticationFilter` 并新增定向测试：

- 携带令牌的请求逐次非阻塞调用现有身份校验接口，复用身份服务原有 Redis/数据库逻辑，不保留本地令牌键表，不引入撤销广播或新依赖。权威校验在撤销提交后开始的新请求应读到撤销结果；已开始校验的请求按该次结果处理。
- 五秒总超时、不自动重试。依赖网络、超时、异常 HTTP、格式或业务故障返回 HTTP 503，不继续下游，也不回退旧身份。只处理认证阶段异常，业务链异常仍交原处理链。
- 明确无效令牌及身份服务 HTTP 401 沿用匿名语义，保护接口由业务权限层拒绝；匿名公共接口不变。先清理伪造身份头，令牌租户与原三维握手约束保持。
- 复用现有静默 JSON 解析，避免异常响应正文被通用解析器写进日志；不输出含令牌的原始异常地址。

每个带令牌的 HTTP 请求多一次内部认证调用，实时连接只在握手时经过此过滤器。原订阅续租、票据及权限检查保持；本批不实现对所有已建立连接的主动退出通知。设计见[第 13 节](../../design/06_IoT定向WebSocket推送交付设计.md#13-网关认证撤销一致性iot-m3-05i2026-11-18)。
