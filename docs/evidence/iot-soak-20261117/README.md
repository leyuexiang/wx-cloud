## 失败和诊断保留

- [固定发布首测](publication-smoke.json)：工具误同时提交草稿及发布范围，50 条订阅均拒绝，零上报；50 票据撤销。
- [数值序号首测](publication-smoke-retry.json)：工具过严地区分整数与整数浮点编码，380 条确认后停止；已修正整数数值同义、仍拒绝布尔及小数，补测试。[修正后短测](publication-smoke-final.json)收到全部 2000 条/100000 次推送。
- [十分钟首轮](publication-10min.json)：约 29 秒触发发送排程落后保护，5360 条/268000 次已发送推送完整；同期浏览器加载，尚不能单凭时间重叠断定原因。
- [同进程复测](publication-10min-retry.json)：530.192 秒触发排程落后 2.092 秒保护；105620 条/5281000 次完整、无重复/客户端错误，第 95 百分位 1276 毫秒，最长确认批次 263 毫秒。配置十分钟未跑满，不能写成通过。随后将发送从 50 路接收线程中隔离，保持原停止门槛。
- 独立发送首次短测为函数迁移遗漏凭据参数，零上报且两票据撤销；新增依赖/确认回执回归后，[23 点/2 连接/30 秒复验](isolated-publisher-smoke-retry.json)通过，覆盖不足 20 项的尾批和续租，再进行最终十分钟满载。
