# PUB-UI-01 统一发布入口与凭证续期验收

2026-11-17，148 测试入口 `/dts/` 的场景管理页与编辑器已统一使用固定快照发布、短期凭证和固定预览合同。当前服务端只声明“受控访问”，前端按真实能力展示；不通过补空字典假定已支持公开、加密、个人或企业访问策略。

## 实施范围

- `GET /dim3d/scene/publication/capabilities` 返回受控发布协议和凭证期限；`POST /dim3d/scene/publication/publish-current` 校验确认时的保存修订。接口按认证租户及管理员角色保护。
- 与保存共用场景行锁；版本变化返回冲突，相同修订复用当前发布，稳定请求编号重放仍返回原回执。复用映射写现有审计表，无业务表迁移。
- 管理页与编辑器使用同一发布弹窗，支持版本确认、固定链接、凭证签发/复制/撤销；管理页更多操作可管理已有发布。列表、详情及已发布筛选统一读取有效当前发布指针。
- 固定链接保留 `/dts/` 部署路径且不带凭证。凭证只驻留内存，关闭弹窗、切换身份或过期后清除，签发响应禁止缓存及请求响应日志记录。
- 有签发权限的登录用户从场景封面进入时自动申请 300 秒凭证，提前 30 秒续签，仅替换内存凭证。失败每 5 秒重试至旧凭证过期后停止运行态。无签发权限时保留手工录入入口。
- 发布弹窗复用管理端与编辑器现有主题样式，修正编辑器深色背景下正文对比度。
