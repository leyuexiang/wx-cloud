## 温度展示与故障复验（2026-11-17）

场景草稿修订 4 新增“温度读数”数字计数器。复用现有动态请求和认证开关，以同源接口读取 `lab-temperature-01 / temperature`，轮询间隔为可配置的 1 秒，按 `value → value` 映射显示三位小数和 °C 单位。原固定发布仍为修订 3。新增温度组件的验收入口为修订 4 的现有编辑模式及运行预览。

| 验收项目 | 实际结果 |
| --- | --- |
| 温度自动展示 | 真实 MQTT 上报 `26.125 → 29.5`，预览显示 `26.125 → 29.500`。同一页面生命周期内完成更新，最近三次状态查询均为 HTTP 200。 |
| 保存与重开 | 重开场景后数值和单位正确，再次进入运行预览通过。服务端四包保存于修订 4。 |
| 浏览器断网恢复 | 仅对当前验收页注入断网，在断网期间经真实代理上报 `28.125`。页面恢复网络后自动显示新值，无页面重载。测试结束已恢复网络。 |
| 重复报文 | 同一温度报文发送两次，只增加一条接收记录，快照事件与已发布记录一致。 |

| 设备隔离 | 温度上报时开关事件编号保持一致，开关 `false → true` 时温度事件编号保持一致。最终开关为 `true`，温度为 `29.5`。 |
