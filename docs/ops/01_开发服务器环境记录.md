## 八、安全注意事项

1. 不要将 root 密码、私钥文件或私钥口令提交到 Git。
2. `wx-cloud_codex` 为临时运维私钥，任务完成后应删除服务器公钥和本地私钥。
3. Redis 若监听 `0.0.0.0:6379`，应配置访问控制和防火墙白名单。
4. CentOS 8 已停止维护，后续建议迁移到 Rocky Linux、AlmaLinux 或其他受支持版本。
5. MariaDB 10.3 与项目 MySQL 基线存在差异，部署前应完成兼容性验证。
