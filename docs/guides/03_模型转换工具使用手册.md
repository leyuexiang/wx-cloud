## fbx2gltf

### 功能介绍

FBX2glTF 是一个将 Autodesk FBX 格式 3D 模型转换为 glTF 2.0 格式的命令行工具。

- **项目地址**: https://github.com/facebookincubator/FBX2glTF
- **Docker 镜像**: `fbx2gltf:latest`
- **配置目录**: `/root/fbx2gltf-docker/`
- **数据目录**: `/root/fbx2gltf-docker/models/`

### 支持的特性

- ✅ 转换 FBX 到 glTF 2.0
- ✅ 支持二进制 .glb 格式
- ✅ 支持嵌入纹理和缓冲区
- ✅ 保留动画数据
- ✅ 保留材质属性
- ✅ 支持混合形状（Blend Shapes）

### Docker 部署

```bash
cd /root/fbx2gltf-docker
docker-compose build
```

### 基本用法

将 `.fbx` 文件放入 `/root/fbx2gltf-docker/models/` 目录，然后执行：

```bash
# 基本转换（.gltf 格式）
docker run --rm -v /root/fbx2gltf-docker/models:/data fbx2gltf:latest /data/model.fbx -o /data/output

# 转换为二进制 .glb 格式
docker run --rm -v /root/fbx2gltf-docker/models:/data fbx2gltf:latest /data/model.fbx -b -o /data/output

# 内嵌资源到 glTF 文件
docker run --rm -v /root/fbx2gltf-docker/models:/data fbx2gltf:latest /data/model.fbx -e -o /data/output
```

### 常用参数

| 参数 | 说明 |
|------|------|
| `-i, --input FILE` | 输入 FBX 文件路径 |
| `-o, --output TEXT` | 输出文件路径（不含后缀） |
| `-b, --binary` | 输出二进制 .glb 格式 |
| `-e, --embed` | 内嵌缓冲区为 data:// URI |
| `--flip-u` | 翻转 U 纹理坐标 |
| `--flip-v` | 翻转 V 纹理坐标（常用） |
| `--no-flip-v` | 不翻转 V 纹理坐标 |
| `--anim-framerate` | 动画帧率：bake24 \| bake30 \| bake60 |
| `--user-properties` | 将 FBX 用户属性导出为 glTF extras |
| `--blend-shape-normals` | 包含混合形状法线 |
| `-v, --verbose` | 详细输出 |

## obj2gltf

### 功能介绍

obj2gltf 是 Cesium 团队开发的 OBJ 格式到 glTF 2.0 格式转换工具。

- **项目地址**: https://github.com/CesiumGS/obj2gltf
- **Docker 镜像**: `obj2gltf:latest`
- **配置目录**: `/root/obj2gltf-docker/`
- **数据目录**: `/root/obj2gltf-docker/models/`

### 支持的特性

- ✅ 转换 OBJ 到 glTF 2.0
- ✅ 支持二进制 .glb 格式
- ✅ 三种材质模式：金属粗糙度 PBR、高光光泽度 PBR、无光照
- ✅ 支持纹理嵌入或分离
- ✅ 支持 MTL 材质文件

### Docker 部署

```bash
cd /root/obj2gltf-docker
docker-compose build
```

### 基本用法

将 `.obj` 和 `.mtl` 文件放入 `/root/obj2gltf-docker/models/` 目录，然后执行：

```bash
# 基本转换（内嵌资源的 .gltf）
docker run --rm -v /root/obj2gltf-docker/models:/data obj2gltf:latest -i /data/model.obj -o /data/model.gltf

# 转换为二进制 .glb 格式
docker run --rm -v /root/obj2gltf-docker/models:/data obj2gltf:latest -i /data/model.obj -o /data/model.glb -b

# 分离缓冲区和纹理文件
docker run --rm -v /root/obj2gltf-docker/models:/data obj2gltf:latest -i /data/model.obj -o /data/model.gltf -s

# 仅分离纹理
docker run --rm -v /root/obj2gltf-docker/models:/data obj2gltf:latest -i /data/model.obj -o /data/model.gltf -t
```

### 常用参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-i, --input` | 输入 .obj 文件路径（必需） | - |
| `-o, --output` | 输出文件路径 | - |
| `-b, --binary` | 保存为二进制 .glb 格式 | false |
| `-s, --separate` | 分离缓冲区和纹理文件 | false |
| `-t, --separateTextures` | 仅分离纹理文件 | false |
| `--checkTransparency` | 检查纹理透明度 | false |
| `--secure` | 防止读取 obj 目录外的文件 | false |
| `--packOcclusion` | 将遮挡纹理打包到金属粗糙度纹理红通道 | false |
| `--metallicRoughness` | MTL 文件已是金属粗糙度 PBR 值 | false |

## 3d-tiles-tools

### 功能介绍

3d-tiles-tools 是 Cesium 团队开发的 3D Tiles 处理工具集，提供丰富的 tileset 操作功能。

- **项目地址**: https://github.com/CesiumGS/3d-tiles-tools
- **Docker 镜像**: `3d-tiles-tools:latest`
- **配置目录**: `/root/3d-tiles-tools/`
- **数据目录**: `/root/3d-tiles-tools/data/`

### 支持的特性

#### Tileset 操作
- ✅ 格式转换（tileset.json ↔ 3tz ↔ 3dtiles）
- ✅ GZIP 压缩/解压
- ✅ 合并 tileset
- ✅ 升级 tileset 版本

#### Tile 内容操作
- ✅ GLB ↔ B3DM 互转
- ✅ GLB ↔ I3DM 互转
- ✅ CMPT 拆分
- ✅ PNTS → GLB 转换
- ✅ B3DM/I3DM 优化
- ✅ 批量/特征表对齐更新

### Docker 部署

```bash
cd /root/3d-tiles-tools
docker-compose build
```

### 基本用法

将 tileset 数据放入 `/root/3d-tiles-tools/data/` 目录，然后执行：

#### Tileset 格式转换

```bash
# tileset 目录转 3tz 包
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest convert -i /data/tileset -o /data/tileset.3tz

# 3tz 包转 tileset 目录
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest convert -i /data/tileset.3tz -o /data/tileset-output
```

#### GLB ↔ B3DM 转换

```bash
# GLB 转 B3DM
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest glbToB3dm -i /data/model.glb -o /data/model.b3dm

# B3DM 转 GLB
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest b3dmToGlb -i /data/model.b3dm -o /data/model.glb

# B3DM 转换为带扩展的 GLB（保留批量表信息）
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest convertB3dmToGlb -i /data/model.b3dm -o /data/model.glb
```

#### GLB ↔ I3DM 转换

```bash
# GLB 转 I3DM
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest glbToI3dm -i /data/model.glb -o /data/model.i3dm

# I3DM 转 GLB
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest i3dmToGlb -i /data/model.i3dm -o /data/model.glb
```

#### 优化

```bash
# 优化 B3DM
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest optimizeB3dm -i /data/model.b3dm -o /data/optimized.b3dm

# 优化 I3DM
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest optimizeI3dm -i /data/model.i3dm -o /data/optimized.i3dm
```

#### GZIP 压缩/解压

```bash
# 压缩 tileset
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest gzip -i /data/tileset -o /data/tileset-gzipped

# 解压 tileset
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest ungzip -i /data/tileset-gzipped -o /data/tileset
```

#### 分析 Tileset

```bash
# 分析 tileset 结构
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest analyze -i /data/tileset
```

### 常用命令列表

| 命令 | 功能 |
|------|------|
| `convert` | 转换 tileset 格式（tileset.json / 3tz / 3dtiles） |
| `glbToB3dm` | GLB → B3DM |
| `glbToI3dm` | GLB → I3DM |
| `b3dmToGlb` | B3DM → GLB（提取） |
| `i3dmToGlb` | I3DM → GLB（提取） |
| `cmptToGlb` | CMPT → GLB（提取所有内部 tile） |
| `splitCmpt` | 拆分 CMPT 文件 |
| `convertB3dmToGlb` | B3DM → GLB（保留批量表为 glTF 扩展） |
| `convertPntsToGlb` | PNTS → GLB |
| `convertI3dmToGlb` | I3DM → GLB（保留特征表为 glTF 扩展） |
| `optimizeB3dm` | 优化 B3DM（通过 gltf-pipeline） |
| `optimizeI3dm` | 优化 I3DM（通过 gltf-pipeline） |
| `updateAlignment` | 更新批量/特征表对齐 |
| `analyze` | 分析 tileset 结构 |
| `gzip` | GZIP 压缩 tileset |
| `ungzip` | GZIP 解压 tileset |
| `combine` | 合并多个 tileset |
| `merge` | 合并 tileset JSON |
| `upgrade` | 升级 tileset 版本 |

## 典型工作流示例

### 工作流 1：FBX → GLB → B3DM → 3D Tiles

```bash
# 1. FBX 转 GLB
docker run --rm -v /root/fbx2gltf-docker/models:/data fbx2gltf:latest /data/model.fbx -b -o /data/model

# 2. 将 GLB 复制到 3d-tiles-tools 目录
cp /root/fbx2gltf-docker/models/model.glb /root/3d-tiles-tools/data/

# 3. GLB 转 B3DM
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest glbToB3dm -i /data/model.glb -o /data/model.b3dm

# 4. 优化 B3DM
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest optimizeB3dm -i /data/model.b3dm -o /data/model-optimized.b3dm
```

### 工作流 2：OBJ → GLB → 3D Tiles

```bash
# 1. OBJ 转 GLB
docker run --rm -v /root/obj2gltf-docker/models:/data obj2gltf:latest -i /data/model.obj -o /data/model.glb -b

# 2. 将 GLB 复制到 3d-tiles-tools 目录
cp /root/obj2gltf-docker/models/model.glb /root/3d-tiles-tools/data/

# 3. GLB 转 B3DM
docker run --rm -v /root/3d-tiles-tools/data:/data 3d-tiles-tools:latest glbToB3dm -i /data/model.glb -o /data/model.b3dm
```

### 工作流 3：批量转换 FBX 文件

```bash
# 批量转换目录下所有 .fbx 文件
cd /root/fbx2gltf-docker/models
for f in *.fbx; do
  name="${f%.fbx}"
  docker run --rm -v $(pwd):/data fbx2gltf:latest /data/$f -b -o /data/$name
done
```

## 注意事项

1. **文件路径**: Docker 容器内路径为 `/data/`，请确保输入输出路径都在挂载的卷内
2. **权限问题**: 如果遇到文件权限问题，可在宿主机上修改文件权限
3. **大文件处理**: 对于大模型，转换可能需要较长时间，请耐心等待
4. **纹理坐标翻转**: FBX 文件通常需要 `--flip-v` 参数来正确显示纹理
5. **3D Tiles 规范**: 生成的 tileset 请确保符合 [3D Tiles 规范](https://github.com/CesiumGS/3d-tiles)
