# 2026-10-23 M2 连接测试验证记录

## 1. 本轮交付

- 新增 `POST /admin-api/iot/connector/test-mqtt`，只引用当前租户已保存 MQTT 连接器。
- 连接测试使用随机客户端编号、清洁会话和 1—15 秒服务端超时。
- 连接成功后逐一订阅确切主题，要求 Broker 授予 QoS 1。
- 测试不取得 Redis 或数据库运行租约，不写运行状态，不进入 Inbox/Kafka，不处理遥测。
- 凭据通过现有凭据解析器获取，响应只返回脱敏结果分类、耗时和主题数量。
- 清理了工作树中两套重复的连接测试 DTO 和重复控制器映射，保留一条实现路径。

## 2. 验证

执行定向测试：

```powershell
mvn -pl wx-module-iot/wx-module-iot-biz -am test `
  '-Dtest=IotMqttConnectivityTesterTest,IotConnectorConnectivityServiceTest,IotConnectorManagementPermissionTest' `
  '-Dsurefire.failIfNoSpecifiedTests=false' '-DskipTests=false'
```

结果（2026-10-23 11:10，北京时间）：**10 项通过，0 失败，0 错误，0 跳过**；Maven `BUILD SUCCESS`。

覆盖范围：

- 成功连接、订阅并强制关闭客户端；
- 凭据不可用时不创建网络客户端；
- Broker 连接失败分类及密码清理；
- 订阅被降级到 QoS 0 时拒绝成功；
- 当前租户配置解析、非 MQTT 协议拒绝、连接器不存在；
- 管理接口权限代理仍保持查询与连接测试权限隔离。

此前先执行过一次编译，IoT 业务模块编译成功；第一次测试编译失败是测试桩嵌套 Mockito 返回值造成的测试代码错误，修正后已通过，不是生产实现失败。

随后使用 148 Redis 环境变量执行联合定向回归：IoT **130 项通过**，三维投影 **27 项通过**，合计 **157 项通过，0 失败，0 错误，0 跳过**；Maven `BUILD SUCCESS`。三维 Redis 三项交互测试实际连接 `192.168.10.148:6379`，连接测试单元不会访问真实 Broker。
