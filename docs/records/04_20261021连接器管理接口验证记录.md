1. 新增连接器 `/page` 管理分页：复用平台分页及响应结构，1—100 条，按编号、协议、启停筛选，数据库显式限定当前租户并按主键降序查询。
2. 新增 `/validate-mqtt-config`：对未保存的 MQTT 参数预校验，复用保存、启用及运行时解析规则，不访问数据库、环境秘密或消息代理；只返回校验范围、主题数量及 QoS。
3. 新增 `/runtime`：同次数据库查询返回管理意图、历史状态、租约期限和数据库观测时间。租约过期优先标为 `LEASE_EXPIRED`；无数据库所有者标为 `UNOBSERVED`，不直接使用历史 `CONNECTED` 判断实时状态。
4. 权限沿用 `iot:connector:query`、`iot:connector:create` 与 `iot:connector:update`；状态查询显式限制租户和逻辑删除。响应不加载或暴露所有权令牌、秘密引用和配置。
5. 原增删改查、启停、单连接及动态运行路径保持兼容；没有新增依赖、线程池、定时任务或数据库字段。

具体请求、响应和状态表见[管理接口指南](../guides/04_IoT连接器管理接口.md)。
