# 文档目录迁移对照

日期：2026-10-19。部分旧位置为本地尚未提交的新增文档，本次首次以分类后的路径入库。Git 内已有文件按内容识别迁移，正文和历史记录保留，仅修正引用、过期当前状态与草案标记。

## 分类及范围

- 详细文档集中到 `docs`；根目录仅保留 `README.md` 和工具必需的 `AGENTS.md` 入口。
- SQL、配置、业务代码和运行时 CSV 留在原模块；这里迁移的 CSV 仅为数据库命名映射参考表，原始字节已与迁移前 Git 基准核对一致。
- BPM 与 CRM 目录中两份相同的单行资料链接合并为一份参考索引，不改转换器业务代码。
- 已重写仓库内 Markdown 相对引用和相关行内文件路径，旧对外链接不会自动重定向，可按本表定位。
