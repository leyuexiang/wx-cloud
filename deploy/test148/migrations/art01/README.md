# ART-01 测试库增量迁移

目标是扩展稳定资源当前内容、显式范围、目录关联及操作快照。新增一张 `wx_dim3d_resource_operation`，初始 81 表库完成后为 82 表。旧表、旧路径及旧默认租户值保留，未分类行不进入新消费查询。

文件按顺序执行：

1. `001-schema.up.sql`：新增字段、索引、检查和同资源操作外键。
2. `002-links.up.sql`：仅回填有真实资源、同租户且双方未删除的模型关联；保持原更新时间。图标/模板不按同号猜测，范围不自动回填。
3. `003-schema.down.sql`：仅供尚未启用新写入的测试库回退，由执行器先检查并撤销本次关联。

已经执行的迁移文件不得修改；后续变化新增迁移。初始 `schema-core.sql` 和 81 表映射作为基线保持原样，不向其中追加已部署的增量变化。

## 执行

上传执行器、验证器和本目录到服务器 `/opt/wx/editor-test148`，从该目录运行：

```sh
python3 verify-resource-art01-migration.py
python3 migrate-resource-art01.py apply
```

验证器新建唯一 `wx_editor_art01_rehearsal_*` 演练库，从既有结构初始化，注入合成旧记录，检查结构/归属/摘要/外键、回填、幂等、回退拒绝、精确回退和重迁移。演练库保留用于审计，未删除或复制真实用户数据。

执行器只允许 `wx_editor_test148` 或本专项演练库；要求 MySQL 8.0.16 以上。每次迁移/回退先备份，保存结构和原字段行摘要、迁移文件摘要与结果。备份和状态文件权限为 600，不输出密码。服务无需因本次扩展结构重启。

重新执行 `apply` 会检查成功记录和结构，匹配时返回 `already-applied`，文件或结构漂移时停止。DDL 不是跨语句事务；中途失败会保留 FAILED 状态和完整备份，须审查部分结构后修复，不自动覆盖重跑。

## 回退

尚未启用新写入、无新资源数据及操作记录、目录关联与迁移记录一致时：

```sh
python3 migrate-resource-art01.py rollback
```

执行器先备份当前库，校验后撤销本次回填，再删除增量结构，并比较原结构及原记录摘要。存在新操作、受管资源、后续关联改动或结构漂移时拒绝回退，不删除资源历史。新接口上线后还须先关闭写入并清空在途请求；生产环境使用前向兼容迁移，不照搬本测试库降级。

备份位于 `backups/art01-*`，状态位于 `.migrations/art01-*.json`。完整备份包含测试身份等私密内容，不复制到 Git；证据仅保留摘要、结构及合成测试结果。

接口与数据合同见[后端设计](../../../../docs/15_资源模板数据结构与接口合同.md)，实施结果见[验收记录](../../../../docs/evidence/backend-art01-20261029/README.md)。
