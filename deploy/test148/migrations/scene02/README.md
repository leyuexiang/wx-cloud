# 场景租户授权增量

先核对目标库已完成场景表改名和发布、票据迁移（DATA-09）。备份 `wx_3d_scene_publication_ticket`，在隔离副本内依次执行 `001-scene-grant.up.sql` 和 `002-ticket-grant.up.sql`。迁移保留普通场景及存量票据。旧票据新增字段默认为空，继续沿用原发布状态及期限规则。

每个场景和目标租户保留一条授权关系。重授时替换授权编号，过去批次的读取票据仍为失效状态。目标租户管理员可换取当前版本只读票据，资源读取以发布方的固定资源索引为准。撤回后拒绝新签发，并停止授权票据的正文及资源读取。已经返回的临时文件地址按原有效期到期。

切换前验证普通票据兼容、授权读取、未授权拒绝、撤回和重授。先完成迁移再切换服务。

回退期间停止新写入并隔离票据流量，备份授权和票据，切回原应用，再按 002、001 倒序回退。002 先撤销仍有效的授权票据，再移除绑定字段。核对原普通票据仍可用后恢复流量。
