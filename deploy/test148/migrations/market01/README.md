# MARKET-01增量迁移

本迁移只增加可空来源字段与独立导入任务表；不修改历史ART迁移、不自动回填旧来源、不改变READY约束。任务通过复合外键绑定原操作及资源，权限与截止时间沿用操作事实。

部署前必须关闭新导入入口、备份并检查当前表结构；只在确认未应用时执行001-import.up.sql。MySQL DDL不是跨语句原子事务，若增加字段成功而建表失败，记录实际结构并修复缺失步骤，禁止盲目重跑。

上限固定首期原ZIP 500MiB，配置只能进一步收紧；提高上限须同步合同和约束。工作线程必须以统一操作行→任务行锁顺序核验身份、截止、尝试与取消；CHECK约束不能代替状态转换和权限检查。

成功状态只是任务投影，查询必须以原操作COMMITTED及committed_revision为准。artifact_descriptor需由后端验证且不可含签名地址；此DDL不替代JSON内容和路径检查。

回退：默认只关闭入口并回退兼容程序，保留新增字段及任务审计。**有任意任务或非空upload_source时禁止删除结构**。仅在停写、无在途任务且确认两者均为空时，可在维护窗口删除新表及约束/列；本轮不提供会误删新数据的一键降级脚本。

当前只在唯一命名的独立演练库验证；未应用到wx_editor_test148。演练库保留用于核验，不自动删除。
